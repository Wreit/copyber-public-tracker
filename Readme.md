# 🚀 Copyber Public Tracker

Welcome to the official public tracker for **Copyber** — the intelligent, privacy-first clipboard manager. This repository exists to gather **community feedback**, report **bugs**, and propose **feature requests** for the Copyber ecosystem.

> **No code is stored here.** This is a discussion and issue-tracking hub for the Copyber user community.

---

## ✅ Current Product Status

Copyber delivers:

- **Cross-platform clipboard history**, built with Avalonia and C#
- **Secure, local-first architecture** with planned optional sync
- **Desktop support for macOS and Windows (stable)**

Next in development:
- **Linux support** (in progress)

---

## 📡 What's Next? You Decide

Once Linux support is completed, we will prioritize the next major direction **based on community input**.

Possible directions:

- 📱 Mobile companion app (iOS & Android)
- ☁️ Cloud sync via personal Google Drive or other providers
- 🤖 AI-powered clipboard search, classification, summarization, mcp integration
- 🛠️ Anything else you suggest

Use this repository to influence that roadmap.

---

## 🧩 How to Use This Repository

1. Go to the [Issues](https://github.com/Wreit/copyber-public-tracker/issues) tab
2. Choose a template:
   - 🐞 **Bug Report**
   - ❓ **Question**
   - 💡 **Feature Request**
3. Fill it out with as much detail as possible
4. Use 👍 on other issues to upvote and guide prioritization

---

## 🔖 Labels and Triage

Issues are labeled for visibility and triage:
- `bug` — Unexpected or broken behavior
- `feature` — Proposed new features
- `question` — Clarifications, usage support
- `needs info`, `help wanted`, etc.
